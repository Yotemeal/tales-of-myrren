Start here
  1. Move something. Choose Move, then drag a tree, ore or building on the map. Hold the scroll wheel down and drag to pan.
  2. Try it in the game. Select Playtest from here, then click a walkable point. Use the Playtest setup to pick a loadout.
  3. Keep your work. Select Save to local game, or export a project file to reopen later.

    Playtest exported map

    In a checkout of the editor branch, run node tools/preview-myrren.mjs and open the editor address it prints. Select Playtest from here and click the map to try the current draft. Use Save to local game when you want to keep it. Keep one of each service building for the playtest.

    Frame tools

    Choose Select pixels, drag a rectangle, then move it one pixel.

    Replace colour by clicking the original pixel after setting the new colour. PNG exports preserve the native frame layout.
