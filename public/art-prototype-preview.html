Bronze / Myrrenite armour prototype

Hand-authored 32×48 native-pixel study. The original Kez V2 silhouette and equipment reference guided the designs, but no game sprite was stretched to make these. This is a separate proof of concept and is not wired into live gameplay.

Preparing prototype renderer…

Four true facings · idle, walk, fist, sword

The shield is face-on in front/back and a slim profile behind the character in side views. Sword movement here is a single visual pose, not the final combat animation. Head, torso, legs, boots, gloves and shield can have independent tiers.

At original world-pixel scale

A 16px tile grid and the current unmodified 21×27 Kez V2 character sit beside the 32×48 proposal. A larger native sprite must earn its space in the world, rather than looking better only when magnified.

Criteria before integration

This prototype is not approved finished art. It tests silhouette, colour, layers and directional positioning. A final production implementation still needs real animated character sprite frames, walking arm/leg sockets, sword impact frames, death, dyes, collision-scale checks, equipment portrait, peer avatars and visual review on a phone. No game systems or saves are changed here.
